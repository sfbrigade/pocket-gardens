# Maintenance records describe history without changing current inventory

Maintenance records can describe planting activities and link plant-directory entries and quantities, but creating, editing, or deleting a maintenance record does not change a garden's current or planned plant inventory. Planting history describes events, whereas plot plantings describe the current or planned state; the prototype's separate planting batches and removals are not represented by the existing one-entry-per-garden-and-plant inventory model. Keeping those boundaries separate lets the first maintenance milestone support corrections without pretending that changing a historical account reliably changes what is growing now. Automatic inventory changes, replanting, and removals require a separate design.
